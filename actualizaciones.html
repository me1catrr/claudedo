Qué cambia en ClaudeDo cuando cambian Claude y Claude Code

Historial público de ediciones de ClaudeDo: versiones de Claude Code consultadas, integradas y comprobadas, modelos contemplados, cambios por unidad y fuentes.

Claude y Claude Code cambian cada pocos días. ClaudeDo separa lo que dura (cómo funciona un modelo, delegar y verificar, privacidad) de lo que depende de una versión (comandos, opciones, precios). Esta página deja constancia de cada actualización: qué se leyó, qué se incorporó al curso, dónde, con qué grado de comprobación y qué queda pendiente. Se genera a partir de los mismos datos que el indicador de versión de cada unidad (_versiones.yml), así que no puede contradecirlo.

Cuatro grados de comprobación. Cada cambio indica cómo se contrastó, de más a menos fuerte:

  1. Ejecución: se ejecutó con un binario concreto de Claude Code (se indica cuál). Lo comprobado en una versión no se da por comprobado en otra posterior.
  2. Simulación: se probó fuera de Claude Code, con datos de muestra, un transporte simulado o un claude falso.
  3. Documentación: contrastado con la documentación oficial vigente en la fecha indicada.
  4. Changelog: solo consta en el registro de cambios oficial; pendiente de comprobación.

Pendiente de comprobación:

  • Comprobar en ejecución, con el binario 2.1.332, lo que en esta edición consta solo como documentación o changelog.
  • Dentro de una sesión real: modos de permiso y su ciclo, /permissions (Recently blocked), /code-review, PreSkillShellCommand, /tasks y /loop.
  • Órdenes que necesitan cuenta o red: claude doctor (conectividad), claude auth status (loginExpiresAt), claude update, claude mcp add-json, claude plugin validate.
  • PowerShell en Windows (y pwsh en macOS, no instalado en esta revisión).
  • Ninguna copia de Claude Code instalada es la 2.1.332 (terminal 2.1.304 y 2.1.300; escritorio y Cursor 2.1.330; VS Code 2.1.306): las comprobaciones de ejecución quedan hechas con 2.1.330.
