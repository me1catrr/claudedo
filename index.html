ClaudeDo enseña a usar Claude y Claude Code con criterio, trabajando sobre casos reales desde la primera unidad: entender qué hace un modelo de lenguaje, delegar una tarea, leer lo que propone ejecutar, comprobar el resultado y decidir qué se integra. Funciona en macOS (Terminal, Zsh) y Windows (PowerShell).

Hecho con Claude Code, para aprender Claude Code: el curso es su propio ejemplo.

Cómo es cada unidad

Teoría breve. Objetivos, prerrequisitos y los conceptos justos, separados de las instrucciones de herramienta, que cambian con cada versión.

Práctica guiada. Pasos para macOS (Zsh) y Windows (PowerShell), con ejemplos en Python y Julia probados en la carpeta _ejemplo/ de la unidad.

Lo que cuesta. Cada práctica dice si es local, una simulación, si requiere cuenta o si puede generar coste.

Hoja de consulta. Terminal, Git y claude, generada desde el registro de comandos verificados.

«Pídeselo a Claude». Un encargo para Claude o Claude Code y un apartado Verifica para comprobar lo que entrega.

Ejercicios. 100 preguntas de autoevaluación dentro del texto; las respuestas se guardan solo en tu navegador.

Versión comprobada. Bajo el título, la versión de la unidad y la de Claude Code con la que se contrastó; las novedades posteriores, en cajas ✦ fucsia.

Datos abiertos. Cinco casos sintéticos (A–E) con semilla fija y ficha de metadatos, en datos/sinteticos.

Novedades de Claude Code por incorporar

El texto de las unidades se contrastó con la documentación de Claude Code 2.1.309. La última versión analizada es la 2.1.317 (changelog leído el 3 de noviembre de 2026). Lo que cambia desde la 2.1.310 y afecta al curso está señalado dentro de cada unidad con una caja como esta:

NotaNovedad · Claude Code 2.1.3xx · por incorporar

Qué cambia, en qué versión y por qué importa en esa unidad.

Leída en el changelog oficial; no ejecutada ni integrada aún en el texto.

  • C1.5 · Protección de datos: Claude Code pregunta antes de enviar a la red el correo de tu cuenta (2.1.317).
  • C4.3 · Permisos: permissions.blockWritesOutsideWorkingDirectories y la pestaña Recently blocked de /permissions (2.1.314).
  • C4.7 · Coste y modelos: ultrathink a esfuerzo xhigh, «límite de 5 horas» y retirada del modo rápido de Opus 4.8 (2.1.311–2.1.316).
  • C7.5 · Hooks: bloqueo con exit 2 en PowerShell, hooks y la herramienta Monitor, límite de simultaneidad (2.1.312–2.1.316).
  • C8.1 · Modo no interactivo: claude -p sale con 1 cuando falla el arranque o el disco (2.1.314, 2.1.317).
  • C8.2 · Subagentes: CLAUDE_CODE_SUBAGENT_EFFORT y esfuerzo por modelo (2.1.316, 2.1.317).
  • C8.8 · Seguridad: escrituras fuera de las carpetas de trabajo y sandbox en worktrees reanudados (2.1.314).
  • C9 · Referencias: la skill claude-api, fuente de la unidad, se actualizó (2.1.314).

Sobre el proyecto
